# 한글 모아모아 도우미 (웹)

메이플스토리 이벤트 미니게임 **한글 모아모아**에서 조각을 어디에, 어떤 순서로, 몇 번 돌려서 놓으면 좋은지 알려 주는 웹 도구예요.
설치 없이 브라우저에서 바로 써요.

> 웹 버전은 게임을 조작하지 않아요. 화면을 보고 추천만 보여 줘요.
> 화면과 이미지는 브라우저 안에서만 처리되고 어디로도 전송되지 않아요 (서버 없음, 외부 요청 없음).

## 쓰는 법

### 1. 실시간 화면 공유 (PC)
1. 메이플스토리를 창 모드로 두고 한글 모아모아 이벤트 창을 열어요.
2. **화면 공유 시작** → **창** 탭에서 MapleStory 창(또는 화면 전체)을 골라요.
3. 판과 오른쪽 조각 패널을 찾으면 놓을 자리 · 순서 · 회전/반전 횟수를 게임 화면 위에 그려 줘요.
   추천대로 놓으면 다음 단계로 넘어가고, 다르게 놓으면 바로 다시 계산해요.
4. **항상 위 HUD 창**을 누르면 게임 옆에 작은 창으로 계속 볼 수 있어요 (Chrome · Edge).

### 2. 스크린샷
게임 화면을 캡처해서 **Ctrl+V**로 붙여넣거나 끌어다 놓으면 판 · 조각 · 능력 개수를 읽어서 추천 순서를 보여 줘요.

### 3. 직접 입력 (휴대폰에서도)
판을 눌러서 칠하고, 가진 조각 3개를 고르면 돼요. **다음 단계 적용**을 누르면 추천대로 놓은 결과로 판이 바뀌어요.

## 계산 방식
- C로 만든 최적화 엔진을 WebAssembly로 빌드해서 써요: 빔 탐색 + 다음 손패 표본 미리보기,
  점 찍기 · 바꿔 뽑기 · 보유 상한(7개) · 다음 능력까지 남은 횟수 · 판 위 아이콘까지 고려해요.
- 평가 가중치는 자기 대전(CEM)으로 학습했어요.
- **계산 세기**가 높을수록 더 멀리 봐요 (끝판: 한 손패에 0.3초 정도).

## 지원 브라우저
- 화면 공유: PC의 Chrome · Edge (권장), Firefox
- 항상 위 HUD 창: Chrome · Edge 116 이상
- 스크린샷 · 직접 입력: 최신 브라우저 모두 (휴대폰 포함)

## 직접 띄우기
정적 파일만 있으면 돼요.

```
python -m http.server 8000
```

그다음 http://localhost:8000 을 열어요 (파일을 더블클릭해서 `file://`로 열면 동작하지 않아요).
